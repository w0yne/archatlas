# Expected: swimlane process (A5/E4)

**Audience:** business and operations. **Question:** who does what, and where does a return change hands?

A correct output has:
- three lanes (customer, support, warehouse); each task sits in the lane of the role that performs it;
- tasks named verb + object, a start and two end events, one gateway with labelled exits (yes / no);
- hand-offs shown by arrows that cross lanes, flowing left to right with no crossings and no line folding back across the page;
- no systems, tables or technology names; the main path readable without the decline branch.
