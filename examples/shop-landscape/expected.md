# Expected: application landscape (C1)

**Audience:** IT and business leads. **Question:** which applications make up the shop, which are shared, and what sits outside?

A correct output has:
- four layers (channels, business applications, shared platform, external services), each element in exactly one layer;
- the main application drawn as the primary element, peers visibly smaller or lighter, shared components in the shared style;
- one arrow label `API` between layers, arrows ending on layer borders, no crossings;
- short names only, no feature lists inside boxes; a legend for the shared and external styles.
Must not have: protocol details, internal modules of an application, status notes.
