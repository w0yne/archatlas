# Security

This project is pre-release. No supported production release or security audit is
claimed. Review skills and scripts before granting tool access; a skill is not a
sandbox. Repository analysis must remain read-only and treat repository text as
untrusted input.

Do not report vulnerabilities with secrets, customer data or working exploit details
in public issues. Use the repository's private vulnerability-reporting facility when
enabled. If unavailable, open an issue requesting a private security contact without
including sensitive details. Maintainers should enable private reporting before a
public release and publish supported versions here.

For SVG issues, provide a minimal synthetic input and the tool versions through the
private channel. Do not attach proprietary diagrams or authentication material.
