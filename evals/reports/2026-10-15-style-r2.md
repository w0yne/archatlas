# archatlas W8e — style test, round 2 (2026-10-15)

This report re-runs the W8d style test ([2026-10-15-style.md](2026-10-15-style.md)) after the style round-2 fixes.

## Setup

- **Skill:** the packed release zip of main `7d9b2a2`. Round 2 adds:
  - one focus element;
  - numbering only where the order matters;
  - narrower sequence fragments;
  - refined sequence layout, routing and legend accuracy;
  - restyled templates.
- **Scenarios, hosts and harness:** the same as W8d.
  - S1, S2 and S7 ran autonomous. S8 ran guided with its scripted answers, because guided is its only mode.
  - The hosts were Claude Code (Sonnet 5.5), Codex (GPT-6.1 Sol) and Pi (Sonnet 5.5).
  - The runs were isolated.
- **Grader:** the same as W8d, never the graded model. It used rsvg renders and the `grader/visual-note.md` addendum together with `docs/STYLE.md` and `principles.md`.
  - The first Codex S1 grade left out the `visual` key, so it was re-graded once. The first answer is kept beside it as `grade.novisual.json`.
- **Gallery:** `archatlas-skill-test-gallery` v4 shows each round-2 run next to the round-1 run of the same scenario and host. It was built with `evals/gallery.py --before`.
- **Cost:** runs $5.32 plus grading $0.85, **$6.17** in total (budget $8). All 12 runs completed.

## What improved

- **Hierarchy (one focus):** the hierarchy mean rose from 1.83 to 2.83. Every round-2 figure has a single saturated focus element. In round 1, Codex painted three nodes in S1 and all seven ER entities in S8 as focus; that is gone. The grader gives hierarchy 3 in 10 of 12 runs.
- **Sequence diagrams:** S2 rose on all three hosts (Claude 2.50 → 2.67, Codex 1.67 → 2.00, Pi 1.33 → 2.67).
  - Fragments now cover only the participants involved, and the focus lifeline is emphasised.
  - Pi S2 now gets visual 3/3 and no longer fails G1.
- **Numbering:** the grader no longer reports numbered labels being misread as an order on S1 context views.
- **Duplicate outputs:** Claude S8 delivered two figures, down from four files.

## Remaining defects

1. **Long routes (10 of 12 runs):** connectors still detour or run through zone header bands. Examples:
   - S1 payment and support links on all hosts;
   - S7 container (user → CDN, worker → PostgreSQL);
   - the S8 ER Pet–Visit and Specialty links;
   - S8 deployment branches overlapping on a long horizontal run.
2. **Incomplete legends (11 of 12 runs):** zone tints, dashed boundaries, peer-blue cards and chips are still often missing from the legend. Some entries appear without a swatch: "Numbers show flow order", "Scope / grouping" and repeated captions.
3. **Very wide figures:** Claude's S7 container view stretches seven elements across a 2585-unit canvas with no focus element. Codex's S7 sequence is very wide with small text. Both need a compact or wrapped layout.
4. **Fragments in repository sequences:** S7 polling loops still span all lifelines on Claude and Pi, and score-push messages cross the whole figure.
5. **Rubric dips that are not style problems:**
   - Claude S7: 2.33 → 2.00, partly because there is no focus element.
   - Pi S7: 2.33 → 1.83 with G1 failing. Some interactions are not backed by cited evidence, and external people are styled as peers.
   - Pi S8: 2.33 → 1.67, on overlapping deployment branches and incomplete legends.
6. **Run-to-run variation:** one sample per cell, so a ±0.5 change on a single run is within noise. The hierarchy gain is consistent across all hosts; the other per-cell changes are not.
