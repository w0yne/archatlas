- **Cause:** a centred label that mixes Latin and CJK is emitted as nested `<tspan font-family=…>` runs under `text-anchor="middle"`.
  - `rsvg-convert` and browsers centre the whole line.
  - CairoSVG centres each run separately, so the CJK run lands on top of the Latin run or outside the box.
- **Effect:**
  - The S9 grader renders showed overflow, and G1 failed for Claude and Pi. The agents' own `rsvg-convert` previews are correct (checked side by side).
  - `atlas preview` uses CairoSVG, so users get the broken picture too.
- **Second issue:** the space between scripts is lost in rendering ("Online shop网店系统"), because the trailing space sits in the Latin run.
- **Evidence:** `results/claude-skill/S9-autonomous-claude-skill/out/diagram.svg`, element `pay-name`.
- **Fix:** emit one positioned line with `text-anchor="start"` and a computed x, or a single font-family stack without inner font runs. Keep the inter-script space as its own run.

### N2. Selection-only answers grew to 6–7 recommended types (regression)
- **Kind:** instruction.
- **What happened:**
  - **S6:** Claude now recommends C2, C3, F2, F1, F3, G2, G3 and Pi recommends six. In W8b each recommended four.
  - G1 now fails 3/3, against 1/3 before. The scenario asks for a small set (2–4).
- **Likely cause:** the new SKILL.md companion-view rule ("say so and deliver it or offer it"). Agents add every companion to the core set.
- **Evidence:** `results/claude-skill/S6-guided-claude-skill/grade.json`
- **Fix:** for selection-only requests, say "recommend 2–4 core types; list companions separately as optional".

### N3. The S2 expectation may be stricter than the scenario
- **Kind:** scenario.
- **The conflict:** S2 asks to "distinguish synchronous calls, replies and asynchronous messages", but the checkout prompt names no asynchronous step. The agents rightly drew none, and the grader fails G1 for it.
- **The frame:** `opt [timeout] retry once` is a guarded frame. Many practitioners accept it for a single retry, but the expectation insists on loop or alt.
- **Fix:**
  - Either add an async step to the prompt (for example "the order service is notified when payment settles"), or relax the expectation to "async messages, if any, are distinguished".
  - Make the E1 reference say which frame to use for a single retry.

### N4. Codex honesty is graded against a fact the trace cannot show (harness)
- **Kind:** harness.
- **What happened:**
  - The report already sets Codex G2 to n/a.
  - The grader still read `image_read: 0` and set Codex honesty to 0 in 7 of 10 runs.
  - Codex median honesty is 1 → 0, and the Codex mean is understated in both rounds.
- **Fix applied after this round's grading** (not used for these grades, so W8b and W8c stay comparable):
  - `grade.py` now passes `image_views_observable` into the trace facts.
  - The prompt tells the grader not to judge G2 or honesty from `image_read` when it is false.
  - The grader renders with `rsvg-convert` when available (see N1).
  - Re-grade both rounds' Codex runs (about $1.2) before relying on Codex honesty.
