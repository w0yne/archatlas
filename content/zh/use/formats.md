# 格式与故障排查

## 初始格式

首个实现目标是**保留可编辑文字的 SVG**，并附带模型 JSON。两者都要保留：模型承载语义关系，SVG 是渲染结果。HTML 只是查看用的外壳。

**尚未承诺：** draw.io 导出、可编辑的 PowerPoint 导出、无损导入或往返编辑。在幻灯片中嵌入一张 SVG 图片，并不等同于原生可编辑的形状。

## 渲染与检查

完整的发布版本提供本地渲染与检查辅助工具。请查看其命令帮助和依赖说明。工作流程为：模型 → 布局 → SVG → 结构/几何检查 → 视觉复核。

## 缺少字体或中文字形

检查渲染器实际选用的字体及字形覆盖情况。使用估算器或回退字体时必须报告。不要靠缩小所有标签来解决裁切问题；应调整换行和布局，然后重新渲染。

## 没有浏览器或不支持图像输入

文本检查和几何检查仍可运行。在支持时生成预览，交给人工或能读图的审阅者。报告**视觉复核待做**，绝不能仅凭命令执行成功就声称视觉检查通过。

## 图过于密集

回到读者的问题。折叠非重点细节，或把不同关注点拆分到不同视图中。保留可查看的全尺寸图片，而不是让标签在小屏幕上无法辨认。
