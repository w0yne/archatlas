# About and licences

archatlas is an English-primary, bilingual reference and skill for choosing and drawing architecture views. Its examples are newly authored; external standards and industry diagrams are linked, not copied. Citation does not grant redistribution rights or imply endorsement.

## Distributed legal files

Original code, documentation and examples use Apache-2.0. Browser dependencies keep their own terms:

- [Apache License 2.0](/LICENSE.txt)
- [Project notice](/NOTICE.txt)
- [Third-party inventory and distribution policy](/THIRD_PARTY_NOTICES.txt)
- [Complete third-party copyright and licence texts](/THIRD_PARTY_LICENSES.txt)
- [This build's third-party module manifest](/third-party-manifest.json)

The full notice file includes emitted JavaScript/CSS dependencies and the Lucide/Feather icons embedded in the theme. It is not just a list of licence names. The site uses system fonts; it does not distribute the optional default-theme webfonts.

## Verification is revision-specific

The [first three-host comparison](/evaluation-report.txt) tested skill revision 3847acb on Claude Code 2.1.285, Codex 0.160.1 and Pi 1.1.0. It did not meet the release gate. Later fixes require their own retained retest evidence; neither the old failure nor a current build result certifies current output quality. See [evaluation guidance](/improve/evals).

## Provenance and contributions

Each type page cites its public standards and research sources. Report an incorrect mapping or missing attribution through the [contribution process](/improve/). Public release/name availability and current-revision certification remain pending; no package is published by this project on PyPI.
